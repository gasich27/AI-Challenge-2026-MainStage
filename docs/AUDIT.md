# Что проверили и поменяли

Проверка: 15 ноября 2026. Это рефакторинг уже проведённых опытов, без нового обучения.

## Что сохранили

- Все 21 ноутбук, включая подготовленный `artifacts_mil.ipynb`.
- Все 162 ячейки с сохранёнными выводами. Числа, таблицы и изображения сохранены. Только в четырёх текстовых выводах абсолютные пути заменены на относительные. Изменилось оформление JSON, поэтому Git показывает большой diff у некоторых ноутбуков.
- 88 файлов с весами, признаками и настройками: SHA-256 до и после совпали. Они остаются локальными, в Git не добавляются.
- PNG/NPZ и исходная разметка не менялись. Для всех 8964 UUID найдены оба файла.
- Старые подробные README меток перенесены в `docs/experiments/`. Там остались отрицательные опыты, ручные наблюдения и ограничения. Удалять эксперименты ради короткого README не стали.

Начальное незакоммиченное изменение — новый MIL-ноутбук. Он сохранён и включён в этот разовый коммит. Резервные копии до правок лежат локально в `.refactor_backup/`, Git их игнорирует.

## Что ещё важно

Validation уже много раз использовали для выбора признаков, моделей и порогов. Это не новая независимая оценка. Internal test тоже уже просмотрен у трёх меток; при будущих решениях нельзя считать его полностью неизвестным.

У старых геометрических CSV нет полного manifest с хешем кода извлечения. Мы проверили ID и имеющиеся модели, но это не доказывает происхождение любого будущего CSV с теми же колонками. Для изменённых формул нужен отдельный кэш.

Размер NPZ на диске не ограничивает его распакованный размер. Выборка граней делается после чтения массивов, поэтому большие меши всё ещё требуют памяти. Старый базовый извлекатель не имеет той же защиты, что новые модули.

Не все DINOv2 модели и test-кэши доступны локально. Для таких строк сохранены выводы выполненных Colab-ноутбуков с явным источником. Недостающие AP/AUC/TP/TN не восстановлены из догадок. DINOv3 не получен из-за доступа к весам, MIL ещё не обучен.

Веса загружаются только из собственных локальных checkpoints. Часть старых PyTorch-файлов требует `weights_only=False`; эти загрузки не предназначены для чужих непроверенных файлов.

Финальный сервис не строился. Общий score отдельно подобранных моделей меток не заявляется: единого прогона по всем одиннадцати выходам ещё нет.
