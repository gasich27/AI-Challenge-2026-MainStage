# Предыдущие эксперименты

Здесь сохранены общий EDA, ResNet18, PointNet++, CatBoost и связка ResNet18 + CatBoost.

Ноутбуки, их выводы, модели и результаты оставлены для сравнения с новыми экспериментами. В коде изменены только пути после переноса.

- `eda.ipynb` — общий анализ данных.
- `cnn_baseline.ipynb` — ResNet18, анализ ошибок, thresholds и fine-tuning.
- `pointnetpp_baseline.ipynb` — baseline на вершинах.
- `catboost_mesh_baseline.ipynb` — CatBoost на mesh-признаках.
- `cnn_mesh_fusion.ipynb` — смешивание вероятностей ResNet18 и CatBoost.
- `models/` — сохранившиеся обученные модели, локально.
- `artifacts/` — признаки, настройки и thresholds, локально.

Общие данные лежат в `../data/`. Ноутбуки находят их при запуске из корня проекта или из этой папки. Пути `models/...` и `artifacts/...` внутри сохранённых конфигураций считаются относительно `archive/`.

Сейчас все пять ноутбуков сохранены с выполненными ячейками. Модели и настройки восстановлены после повторного запуска. Лучший общий score на validation — 0.6284 у ResNet18 + CatBoost с 44 mesh-признаками. Последний PointNet++ получил 0.3698.

Fusion требует checkpoint улучшенной ResNet18, модели CatBoost, таблицы признаков и их конфигурации. Если их нет после очистки, сначала нужно выполнить CNN- и CatBoost-ноутбуки.

Для отдельной Improved ResNet18 итоговые пороги лежат в `artifacts/resnet/resnet18_improved_thresholds.json`. В checkpoint остались пороги baseline, с которыми выбиралась лучшая эпоха; финальные пороги подбираются позже. Для итоговой связки используем её собственные пороги из `artifacts/resnet_catboost_features_config.json`.

Новые эксперименты ведём в `../labels/`. Обучение из архивных ноутбуков может перезаписать их прежние модели и результаты.
